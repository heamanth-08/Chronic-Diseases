## 🌟 Product Overview & Problem Statement

**Assigned Problem Statement:** *"Early symptom prediction system for chronic diseases."*

Chronic conditions such as cardiovascular disease, diabetes, hypertension, chronic kidney disease, and chronic respiratory disorders often progress silently for years before clinical diagnosis. VitaScreen bridges this awareness gap through an accessible, two-stage intelligent questionnaire and machine learning risk estimation pipeline.

### Supported Chronic Disease Categories
1. **Heart-related:** Cardiovascular strain, exertional discomfort, arrhythmia & circulation indicators (Referral: *Cardiologist / General Physician*)
2. **Diabetes-related:** Glycemic regulation, osmotic symptoms, insulin resistance markers (Referral: *Endocrinologist / General Physician*)
3. **Hypertension / Blood Pressure:** Vascular pressure indicators, arterial strain, lifestyle risks (Referral: *General Physician / Cardiologist*)
4. **Kidney-related:** Renal filtration indicators, protein clearance signs, fluid retention (Referral: *Nephrologist / General Physician*)
5. **Respiratory (Asthma / COPD):** Bronchial reactive history, chronic airflow resistance, allergen exposure (Referral: *Pulmonologist / General Physician*)

## 🚀 Quick Start Guide

### Prerequisites
- **Node.js**: v18+ (v24.x recommended)
- **Python**: 3.10+ (3.12+ recommended)
- **Git**

### 1. Installation

Install all backend and frontend dependencies in one command from the project root:

```bash
# Install frontend node modules and root concurrently
npm install
npm --prefix frontend install

# Install backend Python dependencies
pip install -r backend/requirements.txt
```

### 2. ML Pipelines Verification / Retraining

The machine learning models are pre-trained and serialized in `backend/ml/saved_models/`. To retrain the 10 models with 5-fold cross-validation:

```bash
python -m backend.ml.train_models
```

### 3. Running Development Servers

You can launch both frontend and backend concurrently with a single command, or run them independently:

#### Run Both Concurrently (Recommended):
```bash
npm run dev
```

#### Run Frontend Only:
```bash
npm run dev:frontend
# Starts Vite dev server at http://localhost:5173
```

#### Run Backend Only:
```bash
npm run dev:backend
# Starts FastAPI server at http://localhost:8000 with interactive docs at http://localhost:8000/docs
```

## 🔬 Machine Learning Architecture

| Disease | Stage 1 Algorithm (Triage) | Stage 2 Algorithm (Targeted) | Clinical Benchmark Dataset Source |
|---|---|---|---|
| **Heart** | Random Forest | Random Forest | BRFSS 2015 Heart Subset |
| **Diabetes** | Logistic Regression | XGBoost Classifier | BRFSS Diabetes Health Indicators |
| **Hypertension** | Random Forest | Logistic Regression | BRFSS Hypertension Subset |
| **Kidney** | Decision Tree / RF | Random Forest | UCI Chronic Kidney Disease |
| **Respiratory** | XGBoost Classifier | Gradient Boosting | BRFSS Asthma / COPD Subset |

- **Preprocessing:** Median imputation for numeric, StandardScaler for linear models, SMOTE oversampling applied on training splits only.
- **Explainability:** Feature importance and SHAP-based contribution weights translated into clear plain-language insights.
- **Calibrated Risk Thresholds:**
  - `Low Risk`: `< 0.30`
  - `Moderate Risk`: `0.30 – 0.60`
  - `Elevated Risk`: `> 0.60`

## 📄 API Endpoints Summary

| Method | Endpoint | Description |
|---|---|---|
| `POST` | `/api/auth/register` | Register new user account with hashed password (bcrypt) |
| `POST` | `/api/auth/login` | Authenticate user and issue JWT token |
| `GET` | `/api/auth/me` | Fetch active user credentials and profile state |
| `GET` | `/api/user/profile` | Retrieve user health profile & auto-calculated BMI |
| `POST` | `/api/user/profile` | Create/update user health profile |
| `POST` | `/api/assessment/stage1` | Process 15 general questions across 5 models simultaneously |
| `POST` | `/api/assessment/stage2` | Process 10 targeted questions for elevated category + SHAP analysis |
| `GET` | `/api/assessment/history` | Retrieve user's historical screening log |
| `GET` | `/api/assessment/{id}` | Get full breakdown for a specific screening session |
| `GET` | `/api/assessment/{id}/pdf` | Download formatted ReportLab PDF health risk assessment report |
| `GET` | `/api/assessment/compare/{id1}/{id2}` | Side-by-side longitudinal assessment and factor change comparison |
| `GET` | `/api/dashboard/summary` | Dashboard metrics, risk overview, and trend history |
